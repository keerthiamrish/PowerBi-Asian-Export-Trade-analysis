# PowerBi-Asian-Export-Trade-analysis
Project Overview
This project focuses on analyzing international export trade data using Power BI.

Objectives
- Analyze total export value and growth trends
- Identify top exporting countries and regions
- Perform commodity-level export analysis
- Compare year-wise export performance
- Understand currency impact on export growth
  
Data Cleaning & Preprocessing
- Removed duplicate records
- Handled missing and blank values
- Standardized country, region, and commodity fields
- Created calculated columns and measures
- Prepared clean data for analysis using Power Query
  
Tools & Technologies
- Power BI Desktop
- Microsoft Excel
- Power Query
- DAX (Basic Measures)
  
  Files
- Power BI report (.pbix)
- Dashboard screenshots(pdf)
